# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, constructive, and evidence-oriented. Harassment, discrimination, personal attacks,
and publication of another person's private information are not acceptable. Project maintainers may
remove content or participation that violates these expectations.

Report conduct concerns privately to the repository owner.
